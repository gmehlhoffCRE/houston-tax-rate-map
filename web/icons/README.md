Map marker icons, embedded by pipeline/inject.py (a PNG of the same name would win over the SVG).
All three are Cresa Icon Library map pins (Mapping Elements), vector SVG: port.svg (Shipping), airport.svg
(Airport) and rail.svg (PublicTransit_Midnight, used for rail intermodal terminals). The page rasterizes them at
the screen's pixel density and anchors each pin at the bottom-center tip of its pointer.
