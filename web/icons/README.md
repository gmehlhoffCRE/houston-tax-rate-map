Map marker icons, embedded by pipeline/inject.py (a PNG wins over the SVG of the same name).
port.png and airport.png are the Cresa Icon Library map pins (Mapping Elements, Shipping_Icon.svg and
Airport_Icon.svg, which wrap 2132 x 2514 / 2161 x 2549 px images), trimmed and saved at 384 px tall. The page
scales them to the screen's pixel density and anchors each pin at the bottom-center tip of its pointer.
rail.svg is the Cresa Icon Library PublicTransit_Midnight pin (vector), used for rail intermodal terminals.
